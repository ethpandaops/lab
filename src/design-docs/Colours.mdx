# Colours

Every colour is a token, used as a Tailwind class: `bg-surface`, `text-muted`, `border-border`, `text-danger`.
Tailwind's own palette does not compile, so `bg-red-500` and `text-white` do not exist, and lint rejects colour
literals, opacity modifiers such as `bg-primary/10` and `dark:` variants. Each base colour is a `light-dark(light, dark)`
pair with its own star value; the tables show all three.

## Tints

A tint is a colour at part of its strength, a token like any other: `bg-primary-10` is `primary` at 10%. A tint that is
missing is added to `src/styles/tokens.css`, not written inline. The chips follow the toolbar's theme.

<Story of={Stories.Tints} />

## Derived

Colours whose strength differs between light and dark, or that name a role: text on a solid fill, panels, hover
states. Each is defined from other colours, so star follows without its own value. The swatches follow the toolbar's
theme.
