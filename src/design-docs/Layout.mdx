# Layout

## Spacing

Spacing and sizing multiply one step, so any number works: a fixed size is `h-75`, never `h-[300px]`; lint rejects
arbitrary values. Layouts Tailwind has no class for (grid templates, a size less the viewport, card insets) are named
utilities in `src/styles/utilities.css`.
